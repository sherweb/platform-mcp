# Overview

Connect MCP-compatible assistants and automation tools to Cumulus through the Sherweb Cumulus MCP Server at <https://mcp.sherweb.ai>.

The server exposes Cumulus information and actions according to your account permissions. Review important results and changes in Cumulus.

- [Get started](getstarted.html) to create credentials and connect an MCP host.
- [Troubleshoot](troubleshoot.html) to diagnose connection, authentication, and response issues.
