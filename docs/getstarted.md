# Get Started

Connect your MCP-compatible application to Cumulus at <https://mcp.sherweb.ai>.

[Overview](/) · [Troubleshoot](troubleshoot.html)

## Before you begin

- An active Sherweb Cumulus partner account with API access
- A compatible MCP host application
- A Client ID and Client Secret from Cumulus API settings
- The Cumulus permissions required for the information or action you need

For interactive sign-in, you will also need to register the redirect URI provided by your MCP host. Keep your Client Secret and access tokens private.

## 1. Create or select an API credential

1. Sign in to Cumulus and open **Security > APIs**.
2. Create an API credential or select an existing one.
3. Record the Client ID and store the Client Secret securely.
4. If you will use interactive sign-in, keep the host's redirect URI available for registration.

See the [Sherweb setup article](https://helpdesk.sherweb.com/en-us/knowledge-base/articles/KA-05021) for screenshots and Cumulus-specific instructions.

## 2. Configure your MCP host

Use the remote server URL `https://mcp.sherweb.ai`. Follow your host's current setup instructions and register the exact redirect URI it provides in **Cumulus > Security > APIs**.

### VS Code and Cursor

Add the server to your MCP configuration, for example in `.vscode/mcp.json`:

```json
{
  "servers": {
    "sherweb-cumulus": {
      "type": "http",
      "url": "https://mcp.sherweb.ai"
    }
  }
}
```

When the host prompts you, complete authentication with your Cumulus API credentials. See the [VS Code MCP documentation](https://code.visualstudio.com/docs/copilot/chat/mcp-servers) for host-specific details.

### Microsoft Copilot Studio

1. Open your agent and select **Tools > Add a tool > Add a new MCP**.
2. Enter a server name and description, and set the server URL to `https://mcp.sherweb.ai`.
3. Choose OAuth 2.0 with manual configuration and enter your Client ID and Client Secret.
4. Use these OAuth settings:

| Setting | Value |
| --- | --- |
| Authorization URL | `https://cumulus.sherweb.com/oidc/connect/authorize` |
| Token URL | `https://cumulus.sherweb.com/oidc/connect/token` |
| Refresh URL | `https://cumulus.sherweb.com/oidc/connect/token` |
| Scopes | `openid offline_access mcp:tools service-provider` |

5. After creating the connection, register the redirect URI generated by Copilot Studio in Cumulus.
6. Authenticate and confirm that the agent discovers its available tools.

### Other hosts

Claude Desktop, Claude Code, and other MCP-compatible hosts may work. Follow the host's current remote MCP and OAuth instructions; configuration and redirect URI requirements vary by application and version.

## 3. Authenticate and test

Choose the authentication flow that matches your scenario:

| Flow | Typical use | Redirect URI |
| --- | --- | --- |
| Authorization Code with OIDC | Interactive user sessions | Required; register the host-provided URI in Cumulus. |
| Client Credentials | Automation or machine-to-machine workflows | Not required. |

After sign-in, refresh or reconnect the host if needed. Start with a focused, read-only request, such as:

- Which subscriptions are expiring within the next 30 days?
- Show recent audit history for a specific subscription.
- Summarize subscriptions for a specific organization.

Verify important results in Cumulus. For an overview, return to [Overview](/). If something goes wrong, visit [Troubleshoot](troubleshoot.html).
